# Madhava Krishna — Portfolio

Professional portfolio website for Madhava Krishna Koppuravuri.

## Stack
- HTML5
- CSS3
- JavaScript
- GitHub Pages

## Before publishing
1. Replace GitHub and LinkedIn URLs in `index.html`.
2. Confirm the ByBirth live URL and repository URL.
3. Add your latest resume as `resume/Madhava-Krishna-Resume.pdf`.
4. Optionally add project screenshots under `images/`.
5. Enable GitHub Pages from Settings → Pages → Deploy from `main` / root.
